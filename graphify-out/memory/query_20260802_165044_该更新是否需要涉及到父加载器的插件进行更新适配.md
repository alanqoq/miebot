# Q: 该更新是否需要涉及到父加载器的插件进行更新适配

## Answer

Expanded from original query via graph vocab: [plugin, classloader, parent, api, spi, domain, compatibility, requires, version, compile, jar]. No plugin source update is normally required. MieBot 3.2.0 resolves shared API/SPI/domain contracts parent-first while retaining PDA for private libraries. Plugins with Plugin-Requires 3.0.0 through 3.2.0 and compileOnly/provided host contracts remain compatible. Rebuild only plugins that require a newer API, bypass PF4J with their own classloader, or incorrectly bundle/shadow host contracts; removing bundled copies is recommended even though the new host tolerates them. Current mieai-bot 0.0.4 contains zero shared-contract and SQLite entries, so it needs no adaptation.
